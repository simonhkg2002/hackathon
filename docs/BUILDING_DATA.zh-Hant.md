# 地區導覽與輕量樓宇資料

## 已接入

## 18 區修葺令排名

截至 2026-10-06 擷取的資料，**油尖旺區最多：347 份，涉及 269 個樓座**，佔全港 1,787 份中的 19.4%。其後排名：

| 地區 | 累計修葺令 | 涉及樓座 |
|---|---:|---:|
| 油尖旺區 | 347 | 269 |
| 東區 | 187 | 136 |
| 深水埗區 | 164 | 132 |
| 荃灣區 | 163 | 89 |
| 中西區 | 162 | 148 |

統計使用屋宇署 S26 資料中每個 `BLOCK_ID_EN` 的 `Cum_s26Orders_Issued_EN`，以經緯度落入[民政事務總署 18 區分界](https://data.gov.hk/tc-data/dataset/hk-had-json1-hong-kong-administrative-boundaries/resource/46448a93-3343-4e30-ae37-b0e8c4f83bf7)歸區；不按 CSUID 或 3D 輪廓重複計數。1,319 個樓座全部歸區，沒有未配對座標。完整 18 區排名、兩個來源及擷取時間保存在 [`data/district-repair-stats.json`](../data/district-repair-stats.json)。`npm run data:refresh` 會一併更新。

這是**2023 年 5 月起累計發出的第 26 條修葺令數**，不是目前未遵從、正在施工、或裝有棚網的樓宇數。地區較大或舊樓較多亦會影響原始總數；不能直接當成各區危險程度排名。

另找到 [屋宇署樓宇資料及樓齡紀錄](https://data.gov.hk/en-data/dataset/hk-bd-opendata-building-information)，有地址、用途、入伙紙日期。其數字樓座 ID 與地政資料不能在未驗證下直接當成同一識別碼；本版本以地政總署自己的入伙紙關聯作為顯示來源，沒有用最近鄰／地址猜配。

## 仍不能可靠回答的問題

- **正在大維修**：未找到覆蓋全港、逐座可查證施工中狀態的公開即時 API。[市建局維修成本參考](https://data.gov.hk/en-data/dataset/ura-ura-ura-rehab) 有實質完工年份，是歷史參考，不能當成施工中清單。
- **目前需要維修／命令未解除**：累計發出通知不等於現時未遵從。資訊卡另列已遵從／撤銷／被取代紀錄，但統計起點不同，不能直接相減得到可靠的現況。
- **50 年以上＝危險**：沒有這項推論。45–49 年只是此應用的「接近 50 年」分組，並非政府評級。
- 無配對紀錄不代表沒有命令、沒有問題或不需維修。

## 地區導覽與顯示取捨

- 首頁標記的數字是每區有修葺令紀錄的 **`BLOCK_ID_EN` 樓座數**；同一座樓可能有多份命令，也可能有多個 3D 輪廓。市區相鄰標記會自動避讓；完整 18 區始終可由清單選取。
- 點選地區後，鏡頭移至該區有修葺令樓座的位置；地圖只查詢該區目前視野內的官方輪廓。紅色表示曾發出修葺令，**不表示尚未遵從、正在大維修或裝有棚網**。平移可查看同區其他街道。
- 選區後隱藏灰色 OSM 建築以降低雜訊。縮放 13.25–15 顯示紅色平面輪廓；15 以上顯示官方高度的立體輪廓。高度缺失時維持平面，不捏造樓高。
- 伺服器以修葺令樓座 ID 過濾所選地區，避免鄰區樓宇混入。按視野分頁抓取，去除重複 OBJECTID；圖層可過度縮放至近景。17.5 以上逐步限制最大傾角，減少鏡頭穿入高樓的裁切。
- 中英切換涵蓋介面、樓宇資訊卡和 Identify 結果，語言偏好保存在本機瀏覽器。底圖文字仍取決於地圖樣式的字體與語言設定；官方樓宇欄位若無英文會回退至中文。

## 更新及部署

```sh
npm run data:refresh
```

需要 Python 3，使用標準函式庫，從官方公開端點取得資料，不需要 API key。刷新會完整分頁讀取關聯、通知及 18 區邊界，並更新 `data/building-registry.json` 和 `data/district-repair-stats.json`。樓宇關聯與逐座座標保留在伺服器；瀏覽器只取得地區摘要及所選視野的樓宇。刷新後伺服器會在下一次查詢時讀入新快照；重新整理地圖即可看到新資料。

部署須包含 `data/`、`server/` 及 `dist/`。以 `npm run build && npm start` 執行；純靜態部署不能提供 `/api/districts`、`/api/buildings`。本應用已移除精細 3D Spatial Data 模型，無需其 API key。

畫面顯示的是**擷取日期**，不等於官方資料的更新日期。修葺令／驗樓官方 LastUpdate 保存在快照 `updates`，入伙紙資料並非即時更新。建議每月手動刷新，未啟用自動排程。
