# 樓宇及公共地方問題目錄

此清單用於設計報修分類，**不是新屯門中心第 1 座的實際事故紀錄**。目前畫面只預載 9 宗虛構示範個案；正式分類及緊急程度應由管理處和專業人員核定。

| 類別 | 可回報情況 |
| --- | --- |
| 通道與公共地方 | 走廊或樓梯堆放雜物、逃生路線被堵、地磚鬆脫／濕滑、扶手鬆動、玻璃或欄杆損壞、公共照明不足、門鉸／閉門器損壞、垃圾房滿溢或異味、蟲鼠問題 |
| 外牆與結構 | 外牆混凝土或飾面剝落、裂縫擴大、外牆滲水、窗台或簷篷鬆脫、金屬構件鏽蝕、平台／天台防水層破損、公共天花批盪剝落、樓梯踏級破損 |
| 供水、排水與滲漏 | 公共水管漏水或爆裂、走廊／樓梯滲水、天台雨水口堵塞、污水倒灌、排水渠異味、泵房設備故障、水箱滲漏或溢水、公共地方積水 |
| 消防與逃生 | 防煙門無法關閉、消防喉轆或滅火筒損壞、火警警鐘／探測器故障、灑水系統故障、緊急照明或出口指示燈失效、防火閘或排煙設施異常、消防通道被佔用 |
| 升降機與機電 | 升降機停層不準、門無法正常開關、異常震動／聲響、困人、按鈕或樓層顯示故障、機房過熱、公共電錶櫃損壞、電線外露、配電或後備電源故障 |
| 保安與出入 | 大堂或公共出入口門禁失效、對講機故障、公共閉路電視設備損壞、公共門鎖損壞、照明盲點、通道閘門難以開啟 |
| 環境與設備 | 公共通風／抽氣故障、冷氣滴水至公共地方、霉菌或潮濕、異常噪音與震動、公共衞生設施故障、違規棄置廢物、公共標示缺失 |
| 戶外與平台 | 平台地面破損、花槽滲漏、排水口堵塞、樹木或枝條有倒塌風險、外部照明故障、圍欄及欄杆損壞、雨篷鬆脫 |

現時表單只接受樓宇或公共地方問題，不接受私人單位內的報修。高處墮物、外牆剝落、困人、火警及嚴重漏電等可涉及即時危險；示範 ticket 並非緊急求助渠道。
