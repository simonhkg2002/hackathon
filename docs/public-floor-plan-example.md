# 一棟紅色樓宇的公開圖則例子

**新屯門中心第１座**（Sun Tuen Mun Centre Block 1）可作第二層圖則的示範。地圖快取的官方樓宇 CSUID 為 `1432326923T20050430`，修葺令配對地址為 `SUN TUEN MUN CENTRE BLK 1 55/65 LUNG MUN RD TUEN MUN`，與 [28Hse 屋苑頁](https://www.28hse.com/estate/detail/sun-tuen-mun-centre-4426)列出的龍門路 55–65 號及第１座相符。

28Hse 公開列出第１座不同樓層的平面圖，包括 [1–43 樓參考圖](https://i1.28hse.com/estate_data/110/4426/FLOOR/4426_20240205105849953396_large.jpg)。地圖的該棟樓詳情現在連到這張圖及原始頁面，並以 CSUID 限定，避免同屋苑其他座誤用。

這是第三方公開參考平面圖，**不是**屋宇署核准圖則，也未核實圖內單位格局是否仍與現況相同。第二層直接顯示來源網站的圖像並連結原始頁面；專案不儲存圖像副本。若之後要做精確室內 3D 模型，仍須取得該座、該樓層、該版本的可授權核准圖則及尺寸資料。
